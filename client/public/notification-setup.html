Troubleshooting

❌ No Subscription?

1. Check permission: Notification.permission
2. Click "Request Permission"
3. Click "Bulk Demo Subscribe"

🔒 Permission Denied?

Browser blocked it. Go to browser settings → Notifications → Allow localhost

📱 No Service Worker?

DevTools → Application → Service Workers. Should show "active and running"

📊 Check Server Logs

Watch server console for "⚠️ No push subscription found" errors
