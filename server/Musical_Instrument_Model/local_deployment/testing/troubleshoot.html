Common Issues

  • Port 5500 errors: You're accessing this via Live Server. Access directly via FastAPI at port 8000.
  • Connection refused: FastAPI server is not running. Run python main.py
  • Model not loaded: YOLO model file missing. Check for yolo11n.pt or yolov8s.pt
  • CORS errors: Browser security blocking requests. Should be fixed in updated code.
